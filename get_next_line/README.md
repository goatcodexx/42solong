# 📖 Description

**Get Next Line** consists of implementing a function in C that reads and returns a line from a file descriptor.

```c
char *get_next_line(int fd);
```

# Instructions
## The function must:

Return one line per call

Include the terminating \n when present

Return NULL at EOF or on error

Repeated calls allow a file (or standard input) to be read line by line.

This project introduces the key concept of static variables to preserve reading state between function calls.

## Compilation

Compile with:

cc -Wall -Wextra -Werror -D BUFFER_SIZE=42 main.c get_next_line.c get_next_line_utils.c -o gnl

	./gnl <textfile>.txt

Create a main as below:

	#include <fcntl.h>
	#include <stdio.h>
	#include <stdlib.h>
	#include "get_next_line.h"

	int	main(int argc, char **argv)
	{
		if (argc != 2)
			return (1);
		
		int fd = open(argv[1], O_RDONLY);
		char *line;
	
		if (fd < 0)
		return (1);

		while ((line = get_next_line(fd)) != NULL)
		{
			printf("[%s]\n", line);
			free(line);
		}
		close(fd);
		return (0);
	}

-D BUFFER_SIZE=n defines the size used by read().

The program must work with various values (e.g., 1, 42, 9999, 10000000).

A default value should be used if BUFFER_SIZE is not defined.

## Algorithm Explanation

The implementation relies on a static variable to retain unread data between calls.

1. Read and Append

Data is read from the file descriptor in chunks of BUFFER_SIZE using read().
Each chunk is appended to the static buffer until:

A newline (\n) is found, or

End of file is reached

2. Extract Line

Once a newline is detected, the portion up to and including \n is extracted and returned.

3. Update Static Buffer

Any remaining characters after the extracted line are stored back into the static variable for the next call.

4. Error Handling

If read() returns an error → return NULL

If no data remains → return NULL

Memory is freed properly to prevent leaks

## This approach ensures:

Efficient reading

No full-file buffering

Proper handling of small and large BUFFER_SIZE values
